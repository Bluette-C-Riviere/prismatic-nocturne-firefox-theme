# Contributing

Thank you for your interest in Prismatic Nocturne.

## Ways to contribute

- Report rendering or readability issues
- Suggest improvements to the colour palette
- Identify manifest or packaging problems
- Propose documentation improvements

## Before opening an issue

Please include:
- Firefox version and operating system
- Steps to reproduce the issue
- Expected and actual behaviour
- A screenshot when it helps explain a visual issue

## Pull requests

- Keep changes focused and explain the rationale.
- Preserve the minimalist design direction and readability.
- Validate JSON and check all referenced asset paths.
- Do not include unrelated assets or generated build output.

By submitting a contribution, you agree that your contribution may be distributed under the repository's MIT licence. The wallpaper/artwork has separate reuse considerations; do not assume that changing the code licence grants rights to reuse the artwork.
